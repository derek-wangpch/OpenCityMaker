# 斗兽场 / Colosseum

2026-09-06。Tier 10 / value 1024；高等级卡通模型，保留三层拱廊、第四层实墙、内外环与地下遗迹。省略真实的 80 开间、柱头雕刻、逐块砌石与现代设施。

## 本轮参考（已打开图片）

- [官方建筑介绍](https://colosseo.it/en/area/the-colosseum/)：现存遗址背景，非古罗马完整复原。
- [外墙近正面照片及来源页](https://www.podrozepoeuropie.pl/koloseum-rzym/) / [图片](https://www.podrozepoeuropie.pl/images/rzym/koloseum-fasada.jpg)：三层圆拱、平直楼层檐带、第四层矩形小窗及壁柱。
- [Foto aerea del Colosseo](https://commons.wikimedia.org/wiki/File:Foto_aerea_del_Colosseo.jpg)：航拍斜视，长短轴、低矮内环和仅部分保留的高外墙、断端支撑。
- [Rome – Exterior of the Colosseum](https://commons.wikimedia.org/wiki/File:Rome_-_Exterior_of_the_Colosseum_(5178267201).jpg)：另一高位斜视，露天内部、同心看台、地下廊道和部分现代平台。

## 形体约束与卡通取舍

| 项目 | 采用约束 |
| --- | --- |
| 坐标 | y 竖向，x 长轴、z 短轴；高外墙在 −z，A 面为 +z，B 面为 +x，不据照片猜罗盘朝向。 |
| 比例 | 统一 z 缩放 0.76，拱门、墙体与檐带共用同一椭圆；高度适当夸张，以便棋盘辨认。 |
| 外轮廓 | 低内环与高半圈外环分开；外环三层贯通拱廊加第四层实墙；端部降低并加简化扶壁。 |
| 内部 | 三条宽看台台阶、稀疏径向残墙；中央深色地下空间有长廊和横隔墙。 |
| 立面 | 暖石灰华、浅檐带、较深遗迹；32 个游戏开间，附柱分组，顶部隔间小窗。 |

没有获取测绘侧立面，使用两张不同方向航拍约束进深和残墙。缺损边界、扶壁台阶、地下房间排列是依据照片的概括推断，并非逐段考古复原。为可读性省略现代竞技场平台；看台压缩为连续宽带，不代表现存每排座椅完好。
