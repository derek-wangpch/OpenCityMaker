## Supported features (from photos)

Front elevation (entrance close-up):

- Gate = **flush arched opening** in the long front wall, not a protruding
  tower: light-grey stone archivolt band around a semicircular arch, dark
  timber doors set deep in a layered recess (inner arch visible = axis depth).
- **Stone plaque** (鹤湖新居, dark characters on light stone) directly above
  the arch, flush in the wall face.
- **Grey tile coping** runs the full top of the front wall (dark tiled eave
  band, slightly overhanging).
- Sparse small punched windows low/mid on the whitewashed rammed-earth wall;
  wall base darker/soiled.
- Red lanterns + red couplet scrolls flank the gate (festive dressing).

Plan / massing (Shenzhen Museum + exterior photo):

- Two concentric rectangular rings; four corner blockhouses (碉楼) rising above
  the walls; one watchtower (望楼) on the inner-ring front-center axis; central
  ancestral hall (三堂二横) on the axis behind. 月池 + 禾坪 in front (outside
  the wall).
