# 城中村握手楼：错落楼群

本模型表现通用城中村建筑类型，不对应某一栋建筑的精确复原。主要设计依据是用户要求“比较错落，杂乱”，并延续稍微卡通化的风格。

本次检索“深圳 城中村 握手楼 屋顶 航拍”，发现以下参考线索，但来源页和原图均访问超时，未完成图像核对，不作为已验证的几何证据：

有意的风格化：六栋独立楼房采用不同高度、宽深比例和位置；两侧留窄巷，局部阳台向巷内伸出；以少量屋顶加建、水箱、晾衣、雨棚和空调表达生活感。位置与细节为固定设计，无随机生成，以确保棋盘与缩略图一致。没有把设计尺寸当成真实测量值。

验证：实际查看桌面默认角度、旋转角度和手机预览；无页面运行错误，手机弹窗在视口内；类型检查与 35 项现有测试通过，包括模型有限坐标及地块边界检查。
